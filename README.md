# superinstance-math

Pure-Python math libraries for ML engineers. Zero dependencies for core. `pip install superinstance-math` just works.

## Modules

- **information_geometry** — Statistical manifolds, Fisher-Rao distance, KL divergence, Chentsov's theorem
- **optimal_transport** — Wasserstein-1D, Sinkhorn with log-domain stabilization
- **persistent_homology** — Vietoris-Rips complexes, Betti numbers, persistence barcodes
- **spectral** — Graph Laplacian, power-iteration eigendecomposition, spectral embedding & anomaly detection
- **symmetry** — Cyclic, dihedral, symmetric groups; Burnside lemma, orbit-stabilizer theorem
